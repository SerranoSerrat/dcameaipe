Chapter 1

1Get Started

Installation and a first model, end to end.

1.1Installation

dcameaipe isn't on CRAN yet — install the development version from GitHub:

# install.packages("remotes")
remotes::install_github("SerranoSerrat/dcameaipe")

One dependency is optional and only needed if you plan to absorb high-cardinality fixed effects:

# only needed for Z_FE_absorb = TRUE
install.packages("fixest")

1.2What the function fits

dcame_aipe() fits a K-group joint model where each group gets its own flexible function of the treatment, f_k(D) — either a polynomial / B-spline basis (model = "basis", the default) or a penalized GAM smooth (model = "GAM"). For a continuous moderator X, groups are formed by quantile bins (n_parts, default 3); the headline dCAME and AIPE contrast the first and last group.

1.3A first example

Binary moderator, default settings:

library(dcameaipe)

res <- dcame_aipe(
  data     = mydata,
  Y        = "wage",
  D        = "training_hours",   # continuous treatment
  X        = "union",            # binary moderator (0/1)
  Z        = c("age", "female"), # controls
  estimand = "AIPE",
  compare  = "ALL"               # also show D-CAME and the linear-model comparison
)

summary(res)   # data.frame of all estimands
res$plot        # combined PV / IPE / coefficient plot

Continuous moderator, fixed effects absorbed via fixest, cluster bootstrap:

res2 <- dcame_aipe(
  data         = mydata,
  Y            = "y",
  D            = "treatment",
  X            = "education",        # continuous; binned into terciles
  Z            = c("age", "female"),
  Z_FE         = c("country", "year"),
  Z_FE_absorb  = TRUE,               # high-cardinality FE -> feols
  estimand     = "AIPE",
  compare      = "ALL",
  inference    = "bootstrap",        # cluster-bootstrap if `cluster` is supplied
  cluster      = "country"
)

1.4Key arguments

  • model — "basis" (poly/B-spline, default) or "GAM" (mgcv penalized)
  • estimand — "AIPE" or "DCAME" (required)
  • inference — "crossfit" (default, basis only), "bootstrap", or "regular"
  • selection — "CV" (default), "BIC", or "CV_targeted" (AIPE-only)
  • compare — "LINEAR", "DCAME", "AIPE", or "ALL"

See ?dcame_aipe for the full argument list, or the package README for all three inference paths and the pitfalls the function warns about automatically.
